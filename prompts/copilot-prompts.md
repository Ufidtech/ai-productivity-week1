# Copilot Prompt Library

Every prompt below follows the **Task + Context + Format + Tone** framework
from tonight's session. Copy one, swap in your own details, and try it in
Copilot Chat, M365 Copilot, or GitHub Copilot.

## Word

- "Turn these rough notes into a one-page project proposal, for a university
  panel, with a clear intro/body/conclusion, in a formal tone: [paste notes]"
- "Rewrite this paragraph to be shorter and clearer, for a non-technical
  reader, keeping the same meaning: [paste paragraph]"
- "Draft a cover letter for an internship application, based on this CV, in
  three short paragraphs, in a confident but humble tone: [paste CV summary]"

## Excel

- "Write a formula that flags any row where 'Status' is 'Overdue', as a
  conditional formatting rule."
- "Summarize this table into 3 key insights, for a class presentation, as a
  short bullet list: [paste table]"
- "Suggest a chart type to show sales trend over 12 months, and explain why."

## PowerPoint

- "Turn this outline into slide titles and 3 bullet points each, for a
  student audience, in a clear and energetic tone: [paste outline]"
- "Suggest a simple visual layout for a slide comparing two options."

## Outlook / Teams

- "Summarize this email thread into 3 action items, with owners if
  mentioned, in plain language: [paste thread]"
- "Draft a polite follow-up email asking for an update on a group project,
  in a friendly but professional tone."
- "Summarize this meeting transcript into decisions made and next steps:
  [paste transcript]"

## GitHub Copilot (code)

- "Write a function that validates an email address and returns a boolean."
  *(let Copilot suggest inline as you type the function signature)*
- "Explain what this function does and flag any edge cases it might miss:
  [paste function]"
- "Write unit tests for this function using [your test framework]."
- "Refactor this loop to be more readable without changing its behavior:
  [paste code]"

## Tips for better results

1. **Be specific** — "make it better" gives Copilot nothing to work with.
2. **Give real context** — paste the actual document, data, or code.
3. **Ask for reasoning** — "explain why" catches mistakes before you ship them.
4. **Iterate** — treat the first answer as a draft, not a final answer.
5. **Verify** — always double-check facts, figures, and generated code.
