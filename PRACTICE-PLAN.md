# Practice Plan — Week 1 Session

A day-by-day rehearsal checklist counting down to D-Day. Adjust the number
of days if your actual date differs, but keep the order: **setup → isolated
demo practice → one full run-through → dress rehearsal → day-of routine.**

---

## T-4 — Get everything actually working

- [ ] Push the repo to a real GitHub repository (not just the local unzip)
- [ ] Clone it fresh on your laptop to test the real attendee flow
- [ ] **Check whether you have a paid Microsoft 365 Copilot license** (Copilot button visible and working inside Word/Excel ribbon). If not, plan to use free Copilot Chat + copy/paste instead — see `demo-assets/live-demo-script.md`
- [ ] Open `demo-assets/word/outline-raw-notes.docx` in Word — confirm your workflow (in-ribbon or Copilot Chat)
- [ ] Open `demo-assets/excel/event-data.xlsx` in Excel — confirm your workflow (in-ribbon or Copilot Chat)
- [ ] Install VS Code + GitHub Copilot extension, sign in
- [ ] Open `starter-project/` in VS Code, confirm Copilot suggestions appear
- [ ] Replace every placeholder in the deck: `[Your Name]`, `[Date]`, `[your-username]`
- [ ] Generate the real QR code for your live repo URL and drop it into slide 13

## T-3 — Rehearse each demo in isolation (2-3 reps each)

- [ ] **Word demo:** run the exact prompt from `demo-assets/live-demo-script.md`
- [ ] Tweak the prompt now if the output is weak — not live
- [ ] **Excel demo:** run both prompts (comparison table, then chart)
- [ ] Confirm you can explain the formula Copilot writes, if asked
- [ ] **GitHub Copilot demo:** implement the delete-button TODO twice
- [ ] Time each demo against its target (Word ~8 min, Excel ~8 min, Code ~10 min)
- [ ] Screenshot or screen-record your best "after" result from each demo — this is your fallback

## T-2 — One full 90-minute solo run

- [ ] Present the entire session out loud, alone, start to finish
- [ ] Actually run every demo for real — don't skip ahead with "and here I'd show X"
- [ ] Time it with a timer, note where you ran long or short
- [ ] Cut or expand slides based on what you find

## T-1 — Dress rehearsal + logistics

- [ ] Full run-through again, ideally in front of another ambassador
- [ ] Test the actual room's projector/HDMI and wifi if you can get access
- [ ] Charge laptop fully, pack the charger
- [ ] Set up a phone hotspot as backup internet
- [ ] Have a friend scan your QR code from across a room to confirm it works
- [ ] Get a full night's sleep — don't cram new content

## Day of — Final routine

- [ ] Arrive 45-60 minutes early, test projector/screen share and wifi
- [ ] Pre-open: deck, Word doc, Excel file, VS Code + starter project, Copilot Chat tab, repo URL tab
- [ ] Turn off notifications, silence phone, close unrelated tabs
- [ ] Keep your backup screenshots/recordings one alt-tab away
- [ ] Say your first 30 seconds out loud once, right before people sit down
- [ ] After the session: write down what ran long/short and any surprise question, while it's fresh

---

## If live Copilot or wifi fails mid-demo

Don't apologize repeatedly or try to force it to work in front of everyone.
Say something like *"let me show you what this looks like when it runs"*
and switch straight to your T-3 screenshot/recording. Rehearsing that
switch once beforehand is what makes it look intentional instead of like
a failure.

## If Copilot gives a different answer than you rehearsed

It will — it's not deterministic. Practice narrating **why** it did what
it did, not just reading the output aloud. That turns variation into a
teaching moment instead of a surprise.
