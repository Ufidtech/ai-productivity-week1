# Starter Project — Study Tracker

A tiny, dependency-free task tracker (HTML/CSS/JS). It already works — the
point is to **extend** it live using Copilot.

## Run it

No build step needed. Just open `index.html` in your browser, or use the
VS Code "Live Server" extension for auto-reload.

## Your task

Open `app.js` and pick one item from the `TODO` list at the bottom of the
file. Use GitHub Copilot (inline suggestions) or Copilot Chat to help you
implement it. See [`../challenge/challenge.md`](../challenge/challenge.md)
for the full hands-on challenge instructions.
