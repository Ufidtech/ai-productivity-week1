# Hands-On Challenge — Week 1

You've got ~20 minutes. Here's the goal.

## Steps

1. **Clone this repo** (if you haven't already):
   ```bash
   git clone https://github.com/Ufidtech/ai-productivity-week1.git
   ```

2. **Open `starter-project/`** in VS Code (or any editor with GitHub
   Copilot enabled).

3. **Pick one feature** from the `TODO` list at the bottom of `app.js`:
   - Delete button
   - Save to localStorage
   - Due dates
   - Priority tags
   - Filter view (All / Active / Completed)

4. **Use Copilot to help build it.** Try at least 3 prompts using today's
   framework — **Task + Context + Format + Tone**. For example:

   > "Add a delete button to each task in this list, for a plain JS app,
   > keeping the existing style, in a way that's easy to read."

   > "Explain what `render()` does in this file, in simple terms."

   > "Refactor this function to be shorter without changing its behavior."

5. **Test it in the browser.** Does it work? If not, ask Copilot to help
   debug — paste the error message and the relevant code.

6. **Share your result** in the group chat before we close: a screenshot,
   a short description of your prompt, or a link to your fork.

## Stretch goal (if you finish early)

Ask Copilot Chat: *"What's one accessibility improvement I could make to
this app, and how would I implement it?"* — then try it.

## No coding background? No problem

Try the same exercise in **Word or Copilot Chat** instead: draft a short
one-page project proposal for an app idea of your own, using the
Task + Context + Format + Tone framework. Share the prompt you used.
